\section*{{序言}}\phantomsection\label{sec:preface}
% block: preface-purpose page:7 type:ordinary-paragraph
{在科学计算和数据科学的许多领域, 我们经常面临求解形如 $A\bm x=\bm b$ 的大型稀疏线性方程组的问题, 这是整个计算过程中最耗时的部分之一. 因此, 许多研究者致力于开发求解线性方程组的高效数值算法. 如今, Krylov 子空间方法是广泛使用的数值算法, 被认为是 20 世纪十大算法之一, 其他算法包括快速 Fourier 变换和快速排序 \BookCite{39}. 尽管基本理论在 20 世纪就已建立, 数学家, 工程师, 物理学家和许多其他领域的研究者仍不断发展着 Krylov 子空间方法.}
% block: preface-books page:7 type:ordinary-paragraph
{关于 Krylov 子空间方法, 已有许多优秀著作, 包括下列作者的著作:}
\begin{itemize}
\item Owe Axelsson, 1994 \BookCite{10},
\item Richard Barrett et al., 1994 \BookCite{18},
\item Wolfgang Hackbusch, 1994 \BookCite{92},
\item Are Magnus Bruaset, 1995 \BookCite{29},
\item Rüdiger Weiss, 1996 \BookCite{203},
\item Anne Greenbaum, 1997 \BookCite{81},
\item Yousef Saad, 2003 \BookCite{151},
\item Henk A. van der Vorst, 2003 \BookCite{196},
\item Jörg Liesen {和} Zdeněk Strakoš, 2012 \BookCite{122},
\item Gérard Meurant {和} Jurjen Duintjer Tebbens, 2020 \BookCite{129}.
\end{itemize}
% block: preface-features pages:7,8 type:ordinary-paragraph
{文献 \BookCite{129} 详细记述了 Krylov 子空间方法的历史, 是一部关于非 Hermitian 线性方程组的 Krylov 子空间方法的巨著 (约 700 页). 本书的特点如下:}
\begin{enumerate}[label=(\arabic*)]
\item {线性方程组在计算科学和数据科学中的许多应用;}
\item {复对称线性方程组的 Krylov 子空间方法, 如 COCG 方法和 COCR 方法;}
\item {非 Hermitian 线性方程组的 Krylov 子空间方法, 如 BiCR 方法, GPBiCG 方法和 (块) IDR($s$) 方法;}
\item {移位线性方程组的 Krylov 子空间方法, 如移位 IDR($s$) 方法;}
\item {作为移位线性方程组应用的矩阵函数.}
\end{enumerate}
% block: preface-chapter-two page:8 type:ordinary-paragraph
{特点 (1) 对应于 Chapter~\ref{chap:computational-applications}, 其中从各种应用中导出线性方程组: 偏微分方程 (有限差分离散方法和有限元方法); 计算物理: 凝聚态物理 (Green 函数的计算) 和格点量子色动力学 (Wilson 费米子矩阵); 机器学习 (最小二乘问题); 矩阵方程 (Sylvester 型矩阵方程); 最优化 (使用张量计算记号表示 Euclidean 空间和 Riemannian 流形上的 Hessian 矩阵).}
% block: preface-chapter-three page:8 type:ordinary-paragraph
{特点 (2) 和 (3) 对应于 Chapter~\ref{chap:krylov-classification}. 该章将 Krylov 子空间方法分成三类: 针对 Hermitian 线性方程组, 复对称线性方程组和非 Hermitian 线性方程组的方法. 对于 Hermitian 线性方程组, 从 Lanczos 过程的矩阵形式导出 CG 方法, 从 CG 方法导出 CR 方法, 并从 Lanczos 过程导出 MINRES 方法. 对于复对称线性方程组, 分别将 COCG 方法, COCR 方法和 QMR\_SYM 方法作为 CG 方法, CR 方法和 MINRES 方法的推广加以介绍. 对于非 Hermitian 线性方程组, 分别将 BiCG 方法, BiCR 方法和 QMR 方法作为 CG 方法, CR 方法和 MINRES 方法的推广加以介绍. 该章还详细推导了 GPBiCG 方法和 (块) IDR($s$) 方法, 这是本书的特点之一. 此外, 还简要介绍了一些预条件技术.}
% block: preface-chapter-four page:8 type:ordinary-paragraph
{特点 (4) 对应于 Chapter~\ref{chap:shifted-linear-systems}. 该章将移位线性方程组的 Krylov 子空间方法分成三类: 针对 Hermitian, 复对称和非 Hermitian 线性方程组的方法, 并系统地给出这些算法的详细推导.}
% block: preface-chapter-five page:8 type:ordinary-paragraph
{特点 (5) 对应于 Chapter~\ref{chap:matrix-functions}. 如果需要计算大型矩阵函数, 那么 Krylov 子空间方法以及移位线性方程组的 Krylov 子空间方法就是可选的方法, 因为这些算法能够计算矩阵函数中的任意元素. 该章还介绍矩阵函数的定义和一些著名的矩阵函数算法.}
% block: preface-numerical-experiments page:8 type:ordinary-paragraph
{本书的另一个特点是, 除了为进一步理解 Krylov 子空间方法的收敛行为而给出的一些典型数值例子以外, 没有数值实验. Krylov 子空间方法的收敛性高度依赖于系数矩阵, 系数矩阵改变时, 最佳算法也会随之改变. 因此, 如果读者需要求解线性方程组, 我建议对自己的问题尝试若干种 Krylov 子空间方法 (包括 BiCGSTAB 方法和 GMRES 方法), 并从中选出最佳方法.}
% block: preface-conclusion pages:8,9 type:ordinary-paragraph
{本书适合任何学过线性代数并且需要求解大型稀疏线性方程组的读者. 我希望本书能够帮助读者理解 Krylov 子空间方法的原理和性质, 并正确地使用 Krylov 子空间方法求解自己的问题.}
