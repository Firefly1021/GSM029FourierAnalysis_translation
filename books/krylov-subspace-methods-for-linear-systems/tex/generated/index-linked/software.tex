\clearpage\section*{{软件}}\phantomsection
\makeatletter\def\@currentlabel{Software}\label{chap:software}\makeatother\addcontentsline{toc}{section}{软件}

% block: software-historical-reference page:222 type:ordinary-paragraph
{本书侧重于算法设计, 省略了 Krylov 子空间方法的详细历史. 对于希望详细了解其历史的读者, 强烈推荐 Gérard Meurant 与 Jurjen Duintjer Tebbens 的著作 \BookCite{129}. 该书提供了详细的历史介绍, 包含一千余条参考文献, 以及对许多用户都很实用的 Krylov 子空间方法的 Matlab/Octave 函数.}

% block: software-list-introduction page:222 type:ordinary-paragraph
{为方便 Krylov 子空间方法的潜在用户, 下面列出一些可用的软件包.}

% block: software-fortran-ccgpack page:222 type:ordinary-paragraph
\begin{itemize}
\item Fortran 90 ({Piotr J. Flatau 的 CCGPACK 2.0})\par
\url{https://code.google.com/archive/p/conjugate-gradient-lib/}\par
$\to$ downloads $\to$ \texttt{ccgpak2\_0.zip}\par
{用户手册} \url{https://arxiv.org/abs/1208.4869}\par
{提供 COCR, CSYM, BiCGSTAB($\ell$), GPBiCG($m,\ell$), BiCOR 等方法.}

% block: software-fortran-komega page:222 type:ordinary-paragraph
\item Fortran 90 (K$\omega$)\par
{K$\omega$: 移位 Krylov 子空间方法的开源库}\par
\url{https://www.pasums.issp.u-tokyo.ac.jp/komega/en/}\par
{提供移位 CG, 移位 COCG 和移位 BiCG 方法.}

% block: software-gnu-octave page:222 type:ordinary-paragraph
\item GNU Octave ({版本 6.4.0})\par
\url{https://octave.org/doc/v6.4.0/Specialized-Solvers.html#Specialized-Solvers}\par
{提供 CG, CR, BiCG, QMR, CGS, BiCGSTAB, GMRES 等方法.}

% block: software-julia page:222 type:ordinary-paragraph
\item Julia (IterativeSolvers.jl)\par
\url{https://iterativesolvers.julialinearalgebra.org/dev/}\par
{提供 CG, MINRES, GMRES, IDR($s$) 和 BiCGSTAB($\ell$) 方法.}

% block: software-python page:222 type:ordinary-paragraph
\item Python (SciPy 1.8.0)\par
\url{https://docs.scipy.org/doc/scipy/reference/sparse.linalg.html}\par
{提供 CG, MINRES, BiCG, QMR, CGS, BiCGSTAB, GMRES 等方法.}
\end{itemize}
