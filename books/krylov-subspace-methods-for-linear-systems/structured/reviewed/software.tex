% block: software-historical-reference page:222 type:ordinary-paragraph
{The emphasis of this book is on algorithm design, and the detailed history of the Krylov subspace methods is omitted. For those who would like to know the history in detail, the book by Gérard Meurant and Jurjen Duintjer Tebbens \BookCite{129} is highly recommended, and provides a detailed history with more than a thousand references and Matlab/Octave functions of Krylov subspace methods that come in handy for many users.}

% block: software-list-introduction page:222 type:ordinary-paragraph
{For the convenience of possible users of Krylov subspace methods, some available software packages are listed below.}

% block: software-fortran-ccgpack page:222 type:ordinary-paragraph
\begin{itemize}
\item Fortran 90 ({CCGPACK 2.0 by Piotr J. Flatau})\par
\url{https://code.google.com/archive/p/conjugate-gradient-lib/}\par
$\to$ downloads $\to$ \texttt{ccgpak2\_0.zip}\par
{User manual} \url{https://arxiv.org/abs/1208.4869}\par
{COCR, CSYM, BiCGSTAB($\ell$), GPBiCG($m,\ell$), BiCOR and others are available.}

% block: software-fortran-komega page:222 type:ordinary-paragraph
\item Fortran 90 (K$\omega$)\par
{K$\omega$: an open-source library for the shifted Krylov subspace methods}\par
\url{https://www.pasums.issp.u-tokyo.ac.jp/komega/en/}\par
{Shifted CG, Shifted COCG, Shifted BiCG are available.}

% block: software-gnu-octave page:222 type:ordinary-paragraph
\item GNU Octave ({version 6.4.0})\par
\url{https://octave.org/doc/v6.4.0/Specialized-Solvers.html#Specialized-Solvers}\par
{CG, CR, BiCG, QMR, CGS, BiCGSTAB, GMRES, and others are available.}

% block: software-julia page:222 type:ordinary-paragraph
\item Julia (IterativeSolvers.jl)\par
\url{https://iterativesolvers.julialinearalgebra.org/dev/}\par
{CG, MINRES, GMRES, IDR($s$), BiCGSTAB($\ell$) are available.}

% block: software-python page:222 type:ordinary-paragraph
\item Python (SciPy 1.8.0)\par
\url{https://docs.scipy.org/doc/scipy/reference/sparse.linalg.html}\par
{CG, MINRES, BiCG, QMR, CGS, BiCGSTAB, GMRES, and others are available.}
\end{itemize}
