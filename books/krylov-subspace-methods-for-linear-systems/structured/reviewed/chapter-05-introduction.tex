\clearpage\section{{Applications to Matrix Functions}}\label{chap:matrix-functions}
\setcounter{footnote}{0}

% block: matrix-functions-ancient-square-root page:201 type:ordinary-paragraph
{The square root of a positive number received attention in the ancient world. Indeed, an approximation to $\sqrt{2}$ is found in the Yale Babylonian Collection YBC 7289 clay tablet, which was created between 1800 BC and 1600 BC.}

% block: matrix-functions-cayley-sylvester page:201 type:ordinary-paragraph
{On the other hand, the notion of matrix functions such as matrix square root is relatively new: the notion of the square root of a matrix was found by Cayley in 1858 \BookCite{33}, and a definition of matrix functions was given by Sylvester in 1883 \BookCite{180}.}

% block: matrix-functions-modern-applications page:201 type:ordinary-paragraph
{Nowadays, matrix functions arise in many scientific fields such as particle physics, quantum information, and control theory, thus efficient numerical algorithms have been developed by many researchers.}

% block: matrix-functions-chapter-scope page:201 type:ordinary-paragraph
{In this chapter, the definition of matrix functions is described, and then numerical algorithms of matrix functions are described such as matrix square root, matrix $p$th root, matrix exponential, matrix logarithm, and matrix trigonometric function. We will see that Krylov subspace methods or shifted Krylov subspace methods can be useful for computing specific elements of the large matrix functions. The best-known book on matrix functions is Higham's book \BookCite{97}. In what follows, the explanations of matrix functions are based on \BookCite{36}, \BookCite{97}, \BookCite{154}, and the size of matrix $A$ is $n$-by-$n$.}
