\clearpage\section{\BT{Applications to Matrix Functions}{在矩阵函数中的应用}}\label{chap:matrix-functions}
\setcounter{footnote}{0}

% block: matrix-functions-ancient-square-root page:201 type:ordinary-paragraph
\BT{The square root of a positive number received attention in the ancient world. Indeed, an approximation to $\sqrt{2}$ is found in the Yale Babylonian Collection YBC 7289 clay tablet, which was created between 1800 BC and 1600 BC.}{正数的平方根在古代就已受到关注. 事实上, 制作于公元前 1800 年至公元前 1600 年之间的 Yale Babylonian Collection YBC 7289 泥板上就有 $\sqrt{2}$ 的一个近似值.}

% block: matrix-functions-cayley-sylvester page:201 type:ordinary-paragraph
\BT{On the other hand, the notion of matrix functions such as matrix square root is relatively new: the notion of the square root of a matrix was found by Cayley in 1858 \BookCite{33}, and a definition of matrix functions was given by Sylvester in 1883 \BookCite{180}.}{另一方面, 矩阵平方根等矩阵函数的概念相对较新: 矩阵平方根的概念由 Cayley 于 1858 年发现 \BookCite{33}, 矩阵函数的一个定义则由 Sylvester 于 1883 年给出 \BookCite{180}.}

% block: matrix-functions-modern-applications page:201 type:ordinary-paragraph
\BT{Nowadays, matrix functions arise in many scientific fields such as particle physics, quantum information, and control theory, thus efficient numerical algorithms have been developed by many researchers.}{如今, 矩阵函数出现在粒子物理学, 量子信息和控制理论等许多科学领域, 因而许多研究者开发了高效的数值算法.}

% block: matrix-functions-chapter-scope page:201 type:ordinary-paragraph
\BT{In this chapter, the definition of matrix functions is described, and then numerical algorithms of matrix functions are described such as matrix square root, matrix $p$th root, matrix exponential, matrix logarithm, and matrix trigonometric function. We will see that Krylov subspace methods or shifted Krylov subspace methods can be useful for computing specific elements of the large matrix functions. The best-known book on matrix functions is Higham's book \BookCite{97}. In what follows, the explanations of matrix functions are based on \BookCite{36}, \BookCite{97}, \BookCite{154}, and the size of matrix $A$ is $n$-by-$n$.}{本章先介绍矩阵函数的定义, 然后介绍矩阵平方根, 矩阵 $p$ 次根, 矩阵指数, 矩阵对数和矩阵三角函数等矩阵函数的数值算法. 我们将看到, Krylov 子空间方法或移位 Krylov 子空间方法可用于计算大型矩阵函数的特定元素. 关于矩阵函数最著名的书是 Higham 的著作 \BookCite{97}. 以下关于矩阵函数的说明以 \BookCite{36}, \BookCite{97}, \BookCite{154} 为基础, 且矩阵 $A$ 的大小为 $n$-by-$n$.}
