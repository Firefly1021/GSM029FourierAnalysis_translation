# FEEC 封面补齐

日期: 2026-10-23.

按用户要求补齐 AJbook 的独立封面. 以共享收藏中上游 `coverpage.tex` 为依据, 保留中文书名字体、灰黑渐变竖条、横线、交换图与八面体装饰, 将书名与作者换为本书信息. 英文书名作为副标题, 依据长度使用 18pt 字号; 不保留《代数学方法》的卷次、作者、ISBN、专属出版说明或把其整书许可声明移植到译作上. 设计版权与 CC BY 4.0 归属保留在封面源码和本书 README.

封面为 `tex/frontmatter/cover.tex`, 在 `tex/main.tex` 中单独引入, 接在原书出版页之前. 使用独立 titlepage 及空白背页, 随后恢复原前置页计数. 为保留现有出版页、目录的先后顺序, 不将封面挂在同时生成目录的 `frontmatter` 钩子之后. 原始 AJbook.cls 不修改.

中文书名使用官方 Noto Serif CJK SC Bold 静态 OTF, 字体与 SIL OFL 1.1 许可证随书保存; fc-scan 确认家族和字重. 作者区域沿用 Noto Sans CJK SC. 正文字体设置未变. 数学装饰来自上游封面, 不属于原书公式或本书新添的数学正文.
